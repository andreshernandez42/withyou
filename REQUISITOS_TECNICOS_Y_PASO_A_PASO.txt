WITH YOU - REQUISITOS TÉCNICOS Y PASO A PASO
============================================

1. RECOMENDADO
- Windows 11 / Linux / macOS
- CPU 4+ núcleos
- RAM 16 GB (8 GB puede servir, 32 GB cómodo con emuladores/VM)
- SSD con 30-50 GB libres
- 2 teléfonos Android físicos para pruebas de localización y flujo familiar

2. INSTALAR
- Visual Studio Code
- Git
- Docker Desktop (incluye Docker Compose)
- Flutter SDK
- Android Studio (SDK/ADB/emulador; no es obligatorio programar allí)
- Postman
- DBeaver (opcional, recomendado)
- Python 3.12 si ejecutas backend fuera de Docker

3. ARRANQUE BACKEND + POSTGRES
A) Copiar .env.demo -> .env
B) Desde la raíz:
   docker compose up -d --build
C) Crear usuarios demo:
   docker compose exec api python -m app.seed
D) Verificar:
   http://localhost:8000/api/v1/health
   http://localhost:8000/docs

4. BASE DE DATOS EN MOTOR EXISTENTE
- Crear BD PostgreSQL 16 y usuario.
- Ejecutar database/init/00_extensions.sql
- Ejecutar database/init/01_schema.sql
- Ajustar DATABASE_URL.
- Ejecutar python -m app.seed desde backend.

5. MOBILE
- Entrar a mobile/.
- Si no existen android/ios: flutter create . --platforms=android,ios --project-name with_you
- flutter pub get
- Emulador Android:
  flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
- Teléfono Android en la misma Wi-Fi:
  flutter run --dart-define=API_BASE_URL=http://IP_DE_TU_PC:8000/api/v1

6. ESCENARIO DEMO MÍNIMO
- Ingresar como andres@example.com / DemoAndres2026!
- Guardar checkpoint.
- Desde laboratorio, simular sismo M6.6.
- La app muestra Safety Check.
- Responder Estoy a salvo / Necesito ayuda / No puedo salir.
- Ingresar como mamá para verificar notificación.
- Solicitar Welfare Check y confirmar con un segundo contacto.
- Probar intento de acceso no autorizado al endpoint de checkpoint.
- Probar SIRDEC Open Data y link SICLICO.

7. CREDENCIALES
Ver LOCAL_DEMO_CREDENTIALS.txt. Son solo de laboratorio. Cambiar secretos y desactivar ALLOW_TEST_ENDPOINTS antes de exponer la API.

8. FUENTES EXTERNAS
- SGC: adapter ArcGIS configurado en SGC_QUERY_URL.
- SIRDEC Open Data: https://www.datos.gov.co/resource/8hqm-7fdt.json
- SICLICO: se abre como consulta humana con CAPTCHA; no se automatiza.
- IDEAM: definir IDEAM_JSON_URL únicamente cuando se confirme un endpoint oficial/estable para la capa seleccionada. Mientras tanto usar eventos TEST.

9. NOTIFICACIONES
El MVP móvil usa polling mientras la app está abierta, por lo que funciona sin credenciales FCM. Para push en background se debe crear un proyecto Firebase propio y agregar sus credenciales; no se incluyen claves inventadas en este paquete.

10. SEGURIDAD
- Coordenadas exactas cifradas con Fernet en backend académico.
- Passwords Argon2.
- Token firmado con caducidad.
- Nunca exponer .env.demo públicamente.
- Para producción: TLS, secretos administrados, CORS restrictivo, MFA/passkeys, WAF/rate-limit, hardening y revisión jurídica.
